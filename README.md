# TB-SA设计版单自动化上传

> SYNERGY 打版管理系统 — 设计师填写 Excel 模板 + 准备图片，一键上传至系统。

## 用户使用指南

### 准备文件

每次上传需要准备 **1 个文件夹**，内含：

| 文件 | 说明 |
|------|------|
| Excel 表格 | 使用 `config/成衣工艺单_设计师填表模板_v6.xlsx` 填写 |
| 图片 | 按规则命名，放在同一文件夹 |

### 图片命名规则

| 命名 | 对应位置 |
|------|---------|
| `A.png` / `A.jpg` | 基础信息图 |
| `B.png` / `B.jpg` | SKC 详情图 |
| `C1.png` / `C1.jpg` | 工艺详情第 1 张 |
| `C2.png` / `C2.jpg` | 工艺详情第 2 张 |
| `C3.png` ... | 更多工艺详情（支持任意张数） |

> 图片可用 JPG 或 PNG 格式，文件名只保留字母和数字（如 `A.png`），无需加款号前缀。提交成功后系统自动重命名为 `{款号}_A.png`。

### 文件夹结构示例

```
📁 我的设计单/
├── 📄 表单.xlsx          ← 用 v6 模板填好
├── 🖼️ A.png              ← 基础信息
├── 🖼️ B.png              ← SKC 详情
├── 🖼️ C1.png             ← 工艺详情1
├── 🖼️ C2.png             ← 工艺详情2
└── 🖼️ C3.png             ← 工艺详情3
```

提交成功后，文件夹、表格、图片全部自动重命名为 `{款号}` 格式。

### 首次使用

1. 加载 Skill 后自动引导填写姓名和嘉谦系统账号密码
2. 身份验证通过后保存，后续无需重复填写
3. 如需更换设计师，删除工作目录下的 `.identity.json` 重新运行 可交由WB自动执行

## 开发者指南

### 本地测试

```bash
cd skill/src
python submit_excel.py        # 批量处理 mode 会自动扫描文件夹
python -c "from fixed_submit import submit_one; ..."   # 单文件夹测试
```

### 环境变量（可选，优先使用交互式身份流程）

| 变量 | 说明 |
|------|------|
| `MC_USERNAME` | 嘉谦系统账号 |
| `MC_PASSWORD` | 嘉谦系统密码 |
| `MC_USER_REALNAME` | 设计师真实姓名 |

## 依赖

- Python 3.10+
